# 📊 Guide utilisateur — Rapports personnalisés

## À quoi ça sert
Construire ses propres dashboards en glissant-déposant des widgets, sans demander un dev.

## Accès
Menu Direction → **Rapports custom** (`/rapports-custom`).

## Créer un dashboard
1. Cliquer **« Nouveau dashboard »**, lui donner un nom.
2. **Glisser** un widget depuis la palette (Chiffre, Graphique, Table, Liste…).
3. **Choisir la source** : 15 sources whitelistées (établissements, factures, tâches, emails, prospects…).
4. **Configurer** filtres, groupements, période.
5. **Redimensionner** le widget à la grille (drag corners).

## Partager
Chaque dashboard est privé par défaut. Bouton **« Partager »** pour le rendre visible à toute l'équipe.

## Exporter
- **PDF** : rapport mensuel à envoyer.
- **XLSX** : analyse poussée dans Excel.

## Limites
Maximum 12 widgets par dashboard pour garder la lisibilité.
