# 📦 Guide utilisateur — Catalogue produits & services

## À quoi ça sert
Gérer une bibliothèque centralisée des produits/services facturables, réutilisable sur les devis et factures.

## Accès
Menu Direction → **Catalogue** (`/catalogue-produits`).

## Créer un produit
- **Désignation** + description
- **Prix unitaire HT**
- **Taux TVA** (0%, 5,5%, 10%, 20%)
- **Catégorie** (abonnement, prestation, matériel…)
- **Actif/Inactif**

## Utilisation
Sur un devis ou une facture, cliquer **« Ajouter une ligne du catalogue »** : le sélecteur charge tous les produits actifs et auto-remplit prix + TVA.

## Import / Export
- **Export CSV** : sauvegarde complète.
- **Import CSV** : mise à jour en masse (colonnes : désignation, prix_ht, tva, catégorie).

## Permissions
Création/modification : Direction et Commercial. Lecture : tous.
