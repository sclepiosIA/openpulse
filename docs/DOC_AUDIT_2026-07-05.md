1. **`docs/API_REFERENCE_AUTO.md`** — Fichier auto-généré. Il faudrait ré-exécuter `scripts/gen-api-reference-auto.mjs` pour repartir d'une source machine à jour ; le header a été corrigé manuellement en attendant.

Le lecteur doit se référer au bloc "Statistiques projet" de `docs/README.md` pour la vérité courante.
3. **`custom_instructions` (project-knowledge)** — Contient encore "50 pages, 85+ Edge Functions, 140+ hooks" mais ce texte vit hors du repo (paramètres projet la plateforme initiale) et n'est pas modifiable via file edit. À corriger côté paramètres.
